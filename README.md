## 🚀 **QUICK START**

<div align="center">

### **Clone & Run**
```bash
# Clone the repository
git clone https://github.com/mrtonymu/Tonymumu.git

# Navigate to project
cd Tonymumu

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

### **Build for Production**
```bash
npm run build
npm start
```
